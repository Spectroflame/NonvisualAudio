NONVISUALAUDIO — VERSION 2.1.2

Security patch. Backports only the security-relevant fixes from the 2.2
line; no new features.

- Log injection prevented: control characters (newline, carriage return,
  tab, ANSI escapes) in logged values are now neutralised, so a crafted
  file name can no longer forge a second, fake log line.
- Path redaction completed: folder names containing spaces (such as
  "/Volumes/My Drive/Projekt Alpha/…") are now fully stripped from the
  log instead of leaking past the first space.
- Decoder memory guard: the initial PCM buffer is no longer sized purely
  on the container's header duration — which a malformed file can inflate
  at will — but capped at 600 seconds. Genuinely longer files still
  decode correctly.
- Hardened clipboard scan: overlong or null-byte text on the clipboard
  no longer crashes the app at startup; it is treated like any other
  non-path input.


NONVISUALAUDIO — VERSION 2.1.1

Hotfix for the release package.

- macOS packaging repaired: the first-launch helper now ships in the
  zip under the correct file name and is made executable before
  packing.
- Release check added: the CI build now verifies that the app, the
  first-launch helper, and the LIESMICH readme are actually present in
  the macOS zip.
- Download documentation corrected: the macOS artifact is a Universal2
  build for Apple Silicon and Intel.
- CI permissions tightened: write access for GitHub Releases now
  applies only within the release job.


NONVISUALAUDIO — VERSION 2.1.0

Alongside under-the-hood stability work, this update brings the
following new features and bug fixes:

New

- Tighter reports: the analysis output has been overhauled to come
  back more compact and without filler text (silent frequency bands
  are now grouped into a single line).
- Stereo image analysis: a new report block covers correlation,
  mono compatibility, and stereo width.
- Estimated time remaining: the progress bar now shows a live
  countdown alongside the percentage.
- Steadier engine: the analyzer now guards against memory overload
  on very long files (further hardening to come in future releases).
- Export options: reports can now be saved for later review as a
  plain-text file, a heading-navigable HTML file, or a Markdown
  file.

Robustness and privacy

- More robust start: malformed custom genre profiles (genres.json)
  no longer crash the app on launch; each bad profile is skipped with
  a warning and the bundled default profiles stay available.
- Leaner logging: with normal logging no folder or user names reach
  the log file anymore — not even for import/export paths that
  contain spaces.

Bug fixes

- macOS import fix: hidden system files are now skipped when
  importing folders and no longer crash the engine.
- Clipboard-drop fix: Cmd+V and Ctrl+V now trigger reliably on the
  first try. The app also detects whether the focus is in the
  target area or the reference area and pastes the content
  accordingly.
- Interaction polish: assorted smaller improvements to interaction
  and screen-reader output; a running analysis can now be cancelled
  via the button or Escape.
