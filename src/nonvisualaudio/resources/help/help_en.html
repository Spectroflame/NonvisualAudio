1. Overview

NonvisualAudio measures the same things a sighted engineer reads off a visual analyzer — integrated loudness, true peak, loudness range, dynamics, and spectral balance — and writes them out as a plain-text report with no visual chart required. The report is structured in clearly labelled sections that every screen reader can walk line by line.

Everything runs locally. There is no cloud, no telemetry, no network calls.

2. Quick start

  1. Press Add Audio Files... or drag files/folders onto the window, or paste copied files with Cmd+V / Ctrl+V.
  2. Optionally pick one or more genres under Choose Genres... so the report includes a comparison.
  3. Optionally pick a reference audio file via Choose Reference File... for an A-versus-B comparison.
  4. Press Analyze (or Cmd+R / Ctrl+R).
  5. The report opens in its own window. Read it with your screen reader, copy it with Cmd+Shift+C / Ctrl+Shift+C, or close with Escape.

3. The main window

The main window has four input areas, stacked top to bottom, plus the Analyze button at the bottom:

Audio files list
A read-only text field that lists every audio file currently queued for analysis. Each file gets its own section in the resulting report. Clear Files empties the list.
Selected genres
Shows which genre profiles the report will compare against. Press Choose Genres... to open the picker; you can select any number at once.
Reference
Shows the audio data acting as the A/B reference — either a single file or several files combined into a reference project; see Reference comparison. Clear Reference removes it.
Selected report sections
Shows which blocks the rendered report will contain — all of them, or a subset like loudness only or frequency balance only. Choose Report Sections... opens the picker; see Choosing report sections.
Project mode
A "Analyze all files together as one project" check box; off on every launch. See Project mode for albums and audio dramas.
Analyze / Cancel
Starts the analysis (also Cmd+R / Ctrl+R). While an analysis is running, the same button turns into Cancel, so there is only ever one primary action. A running analysis can be cancelled from that button or with Escape; a short "Cancel analysis?" confirmation appears before the run is actually stopped.
Progress bar and status line
Appear while an analysis is running. The status line also sits in the tab order, so a screen reader can focus it to hear the current phase, the percentage, and a continuously updated estimate of the remaining time.

A metronome-style click plays during the analysis so you have audio feedback that work is progressing. Nothing is written to disk for that — the click sample stays in memory.

4. Menus

Edit

Edit Genre Profiles... (Cmd+G / Ctrl+G) opens the genre editor — see Genre profiles.

View

Four colour schemes, each a radio-button entry:

  • Automatic (system) — follows the OS light/dark setting.
  • Light — white background, black text.
  • Dark — dark grey background, light text.
  • High Contrast — black background with saturated yellow text for maximum readability with low vision.

The switch happens immediately, no restart required, and the choice is remembered across app launches.

Language

Three entries:

  • Automatic (system) — read from the OS locale.
  • English.
  • Deutsch.

The new language takes effect after you restart NonvisualAudio.

Help

About NonvisualAudio (F1, or Cmd+Shift+ß on a German Mac keyboard) opens a compact About / Help dialog. It carries the version, description, licence, credits, and the GitHub link, plus two action buttons:

  • Show README opens this user guide in your default browser, in the currently active interface language.
  • Report a Bug opens the project's GitHub issue tracker so bug reports take two clicks instead of digging through menus.

5. Measurements explained

5.1 Loudness (LUFS, LU)

Integrated loudness
The average loudness over the entire file, measured in LUFS (Loudness Units relative to Full Scale) following the EBU R128 and ITU BS.1770 standards. Streaming platforms use this number to normalise playback volume. Typical targets: minus 14 LUFS on Spotify/Apple Music, minus 23 LUFS for European broadcast, minus 16 for conversational podcasts.
Short-term peak loudness
The loudest three-second segment in the file, in LUFS. If it is more than roughly 3 LU louder than the integrated value, the file has meaningful loudness variation; if it is very close, the file is heavily compressed.
Loudness range (LRA)
How much the loudness varies across the file, measured in LU (Loudness Units). Small values (3 to 6 LU) mean a squashed master; large values (14 to 24 LU) mean a very dynamic recording with soft passages and loud climaxes.

5.2 True peak (dBTP)

The highest instantaneous sample value after oversampling — a closer approximation of what the analogue output will actually produce than the raw sample peak. Values above minus 1 dBTP risk inter-sample clipping during lossy playback (MP3, AAC, streaming transcodes). A common safe ceiling is minus 1 dBTP; stricter workflows set minus 2 dBTP.

5.3 Dynamics (crest factor and DR score)

Crest factor (dB)
The difference between the peak and the RMS level of the file. A sine wave has a crest factor of about 3 dB. Music typically sits between 6 dB (heavily compressed pop/metal) and 16 dB (classical, acoustic jazz). Dialogue and audiobooks usually land around 10 to 14 dB.
Dynamic range score (DR)
A simplified integer roughly following the "DR" mastering community convention. Higher is more dynamic. Anything below DR 7 usually sounds flat and fatiguing; DR 10 and above feels open.

5.4 Frequency balance and bands

NonvisualAudio splits the audio spectrum into six bands and reports the energy in each one. The report names the loudest band first and then expresses every other band as "X dB quieter", so you can compare by ear without picturing a chart.

Sub-bass (20 to 80 Hz)
Rumble, sub-kick, low-frequency effects.
Bass (80 to 250 Hz)
Fundamental of most bass instruments and low male vocals.
Low midrange (250 to 500 Hz)
Body of vocals, guitars, snare. Too much here sounds boxy.
Midrange (500 Hz to 2 kHz)
Core of intelligibility. Vocal presence lives here.
Presence (2 to 6 kHz)
Clarity, bite, consonants. The ear is most sensitive here.
Air (6 to 20 kHz)
Cymbal sheen, string harmonics, breath, sibilance.

5.5 Spectral peaks

A spectral peak is a narrow resonance that stands out several dB above the surrounding spectrum at a specific frequency. NonvisualAudio finds them and reports each one with:

  • its frequency in Hz (or kHz),
  • the region it falls in (sub-bass, bass, low midrange, midrange, presence, or air),
  • how many dB it sticks out above the surrounding spectrum,
  • a plain-language note on what it typically sounds like (for example "boxiness", "sibilance", "nasal or telephone-like").

The Recommendations section of the report then suggests a concrete EQ starting point for each peak: a cut amount, a Q value, and the technique best suited to the region (narrow notch for mains hum, broad bell for midrange, de-esser or high shelf for the top end, high-pass filter for sub-50 Hz rumble).

5.6 Stereo image (correlation, mono, width)

For stereo files, NonvisualAudio judges the stereo image with three numbers — what a sighted engineer would read off a goniometer, in plain words:

L/R correlation
How alike the left and right channels are, on a scale from minus 1 to plus 1. Plus 1 means fully correlated (effectively mono), 0 means uncorrelated (wide stereo), minus 1 means out of phase — which points to a phase problem. Alongside the mean, the worst block value is reported too, so a brief out-of-phase moment is not hidden by the average.
Mono level drop
How many dB the level falls when the file is summed to mono (0 dB means no loss — full mono compatibility). Important for playback on a single speaker, a phone, or a kitchen radio.
Stereo width
The ratio of side energy to mid energy. Very narrow means almost everything sits in the centre; unusually large points to stereo-widening effects or an accidental phase reversal.

For mono files (or an all-mono project) the stereo image block is skipped with a note to that effect. When the readings are critical, the report adds concrete guidance in the Recommendations section.

6. Genre profiles

NonvisualAudio ships with 42 genre profiles across 13 categories (audio drama, podcast, spoken word, pop, rock, rap and hip hop, R&B and soul, reggae, jazz, folk and country, electronic, classical, film and cinema). Each profile carries a typical loudness target (LUFS), a typical loudness range window (LU low to LU high), and a short description of the genre's tonal character.

Pick one or more genres before analyzing. For each selected genre, the report will include a "Comparison to ..." section that tells you whether the file is louder or quieter than the genre's typical target and whether its dynamics are within the typical range.

Editing genre profiles

From Edit → Edit Genre Profiles... you can add, change, delete, or reset profiles. Each entry in the list carries an origin tag:

  • built-in — a stock profile that ships with the app.
  • user — a profile you added yourself.
  • modified — a stock profile whose values you overrode.

At the top of the editor, the Show: popup menu narrows the list to All, Built-in, User, or Modified entries — handy for finding the few profiles you've added or tweaked among the 42 shipped ones.

Delete is only available for user entries. Reset to Built-in applies to modified entries and restores the stock values.

Add / edit profile form

In the form, every field has its label directly above it so screen readers announce the name when you tab into the field. Initial focus lands on the Key field.

The category is picked from a popup menu (VoiceOver: "popup menu"). The default selection is <please select>; pressing OK without choosing a real category triggers a validation error. To create a new category, type the name into the dedicated Or new category name field below the popup — when filled, it overrides the popup selection.

When you leave the Target LUFS, LRA low, or LRA high fields, the input is auto-tidied into the form the rest of the app expects: "-15" becomes "-15.0", "3,5" becomes "3.5". Anything that does not parse as a number is left untouched and surfaces a validation error on OK.

When adding a profile, you can fill in both an English and a German name and description; the report will pick the correct language automatically. Any changes live in your user data folder — the shipped profiles are never overwritten. When you delete the last user profile, the override file is removed; the data folder only keeps content while there is something to save.

7. Reference comparison

Pick reference audio via Choose Reference Files.... The multi-select dialog accepts one or several files; alternatively drop a folder onto the reference area. There are two modes depending on how many files you pick:

  • One file — the classic A/B comparison. The report includes loudness difference, dynamics difference, and band-by-band spectral differences.
  • Several files or a folder — every reference file is fed through the same project-mode pipeline as the target and combined into a reference project (loudness measured exactly via the ffmpeg concat filter, dynamics and spectrum on the concatenated samples). Useful for A/B'ing a freshly mastered album as a whole against a previously released album as a whole — master vs. master rather than track by track.

The opening line of the comparison section reads "Reference filename: …" for a single file or "Reference project: …" for multiple files. Reference and genre comparisons combine — every genre you pick plus the reference each produce their own section in the report.

8. Choosing report sections

By default the report contains every block (file info, loudness, dynamics, frequency balance, overall assessment, comparison, recommendations). The Choose Report Sections... button on the main window lets you enable just the blocks you want — for example only loudness, or only frequency balance plus recommendations.

The picker dialog has a check box per section, plus Select all and Select none shortcuts. Your selection is remembered between launches, so you only need to set it once.

9. Project mode for albums and audio dramas

The Analyze all files together as one project check box treats the whole selection as one continuous piece:

  • Loudness, dynamics, and frequency balance are measured across every track as if the collection were one big bounced file. Loudness is computed via the ffmpeg concat filter feeding ebur128 — exact, not an averaging approximation.
  • The report header reads "PROJECT" instead of "FILE INFO". The verdicts address the project directly ("The project is loud..." instead of "The file is loud...").
  • An additional "CROSS-TRACK CONSISTENCY" block reports the spread of per-track integrated loudness and names the loudest and quietest track.

Safety nets:

  • Project mode is always off when the app starts, so it cannot silently persist from an earlier session.
  • If project mode is on but only one file is in the list, the app asks before analyzing: switch back to a regular single-file run, run the file as a one-track project anyway, or cancel to add more files first.

10. Reading the report

The report is plain text. Section headings are written in ALL CAPS on their own line, so screen readers can jump between them. The sections always appear in this order:

  1. FILE INFO — filename, duration, sample rate, bit depth, channels.
  2. LOUDNESS SUMMARY — integrated LUFS, short-term peak, true peak, LRA, plus a one-sentence verdict.
  3. DYNAMICS SUMMARY — crest factor, DR score, and a one-sentence verdict.
  4. FREQUENCY BALANCE — loudest band as the anchor, other bands as "X dB quieter", overall spread, plus any spectral peaks with their frequency and character note.
  5. OVERALL ASSESSMENT — a one-paragraph summary combining loudness, dynamics, and tonal lean.
  6. COMPARISON TO ... sections — one per selected genre and one for the reference file or reference project, if any.
  7. STEREO IMAGE — L/R correlation, mono level drop, and stereo width, each with a one-sentence verdict (skipped with a note for mono files).
  8. RECOMMENDATIONS — concrete EQ and mastering suggestions derived from the measurements.
  9. In project mode, an additional CROSS-TRACK CONSISTENCY block — one line on per-track loudness spread plus the loudest and quietest track.

Which blocks actually appear depends on the selection in Choosing report sections.

Numbers are spelled out: "minus 21.4 LUFS" rather than "-21.4 LUFS" on English, "minus 21,4 LUFS" on German, so a screen reader always speaks them naturally.

Copying and exporting the report

The results window has two buttons at the bottom for handing the report on:

  • Copy Report puts the whole text on the clipboard (also Cmd+Shift+C / Ctrl+Shift+C).
  • Export... saves the report to a file. The format follows the chosen extension: .txt for plain text, .html for a self-contained page with navigable headings (jump heading to heading with a screen reader in the browser), or .md for Markdown.

12. Privacy and data

No data is ever sent over the network. NonvisualAudio has no telemetry, no cloud, no analytics. A very small preferences file is written to your user data folder only when you explicitly change the language or theme. Custom genre profiles go into the same folder. Locations:

  • macOS: ~/Library/Application Support/NonvisualAudio/
  • Windows: %APPDATA%\NonvisualAudio\
  • Linux: ~/.config/NonvisualAudio/
